# AI星球 · 项目设计

## 产品定位

面向小学高年级至初中的课堂体验。目标不是训练编程技能，而是让学生能解释“AI 为什么这样判断”“结果是否可信”“怎样负责地改进”。一个浏览器实例对应一位学生或一个小队，不提供多人联机。

## 叙事与循环

数据风暴损坏智能核心。训练师按数据、训练、推理、改进的路径走遍八个区域，每次完成实验获得芯片和徽章。核心循环：阅读任务 → 操作或讨论 → 提交证据 → 反馈修正 → 获得芯片 → 反思迁移。

任务地图、资源状态、侧边进度保持可见。只开放下一关；已完成关可查看作品，不能重复刷币。没有倒计时淘汰，错误允许无限次重试，学生也可用算力币换帮助。

## 视觉与交互

- 方向：自然色系的太空实验站，浅米灰背景、深森林绿主视觉、荧光绿行动按钮。
- 星球插画由 CSS 构建，强调核心修复；卡片以低饱和度色彩区分区域。
- 桌面四列任务地图，较小屏幕两列；移动端隐藏辅助侧栏、保留导航与任务入口。
- 原生对话框、表单标签、焦点样式、状态播报、跳转链接和减少动画支持。
- 通过依次解锁和直接反馈控制认知负担，知识解释不靠惩罚推进。

## 教学修订

原提示词“数据越多越好，但不一定越干净越好”容易误导，修订为“为什么更多不一定更好？干净的数据是否也可能缺乏代表性？”

原场景“白猫训练后其他猫全错”作为偏差示例，不呈现为真实模型的必然结果。数量均衡不等于所有公平问题都被解决，必须强调分组评估与环境代表性。

提示词关明确区分规则模拟与真实生成式 AI。幻觉关使用游戏内虚构档案作为可完整核实的原始证据，避免把联网检索能力作为通关门槛。伦理议会评价负责任的原则，不自动裁定法律归属。

## 数据模型

`localStorage['ai-planet-v1']` 包含版本、小队代号、教学节奏、算力币、数据卡、完成关卡、得分、答案、提示、辅助使用、随机事件与协作自评。

恢复时过滤非法字段，损坏数据回退初始状态。存储失败时仍可玩并提示导出。客户端存档可被使用者修改，因此此系统不适合考试、防作弊或高风险评价。开放题只做形式检查。

## 验收场景

1. 初次进入显示 5 币、0 芯片，只可进入第一关。
2. 错误提交不通关、不扣币；提示只扣一次，余额不足时不透支。
3. 关卡完成后下一关解锁；重新打开已完成关不会再次发奖励。
4. 关闭网页再访问保留进度；存档损坏能重新开始。
5. 提示词修改后必须重新生成，不能提交旧作品。
6. 八关完成后显示奖项；协作评价参与金牌条件。
7. 护照能导出与打印；重新开始需要二次确认。
8. 手机视口可完成关卡，不依赖悬停或拖拽。

## 明确不包含

真实训练、真实生成 API、在线协作、班级管理、账号体系、成绩服务器、计时竞赛、自动内容质量评分、导入存档。它们是后续扩展方向，不属于当前功能承诺。
