# 不插电活动包

本文件可用 Markdown 阅读器打印。配合卡纸、贴纸与海报使用；网页中的图标卡可由教师画成简笔图。

## 准备 30 张数据卡

- 01—22：清晰、标签正确。按“猫、狗、其他”循环绘制，其他可统一画仙人掌。
- 23—26：模糊图。遮挡或打散线条，标签按同样顺序填写。
- 27—30：错标签。27 画仙人掌标“猫”；28 画猫标“狗”；29 画狗标“其他”；30 画仙人掌标“猫”。

给每张卡一个编号，不使用学生照片。分发“猫 / 狗 / 其他 / 剔除”四种标签。

## 关卡任务卡

| 区域 | 教师发放 | 小队产出 |
| --- | --- | --- |
| 数据采集 | 30 张卡片 | 至少 20 张正确干净数据，解释剔除原因 |
| 训练工坊 | 训练 3、10、20 轮报告：训练 54%、82%、100%；测试 57%、91%、59% | 选择合适模型，解释过拟合 |
| 推理测试 | 猫→猫85%、狗→猫99%、黑猫→狗91%、狗→狗61%、仙人掌→猫55% | 判断五次预测，说明为什么高置信度也会错 |
| 偏见迷宫 | 白猫18、黑猫0、花猫0的筹码板 | 每类至少6张，数量相差不超过2；讨论分组测试 |
| 提示实验 | “画一只猫”与完整提示词示例 | 写详细提示词，另一位同学按提示绘画，比较结果 |
| 幻觉沼泽 | 教师指南中的档案与三条陈述 | 找两处矛盾，指出原始证据 |
| 伦理议会 | 校园AI美术展角色卡 | 隐私、版权、责任各一条规则 |
| 未来工程 | 海报纸 | 校园问题、感知、思考、行动、技术作用和失败处理 |

所有训练数值为预设教学模拟。纸质模拟与网页的训练公式一致。

## 故障与补给卡

1. **数据泄露警报**：扣 1 枚币（最低 0），说出一项不该上传的信息。本卡模拟风险，不要求实际收集数据。
2. **开源补给**：加 1 枚币，说出使用他人作品前需要确认的一件事。
3. **正常巡航**：顺利送回芯片，分享本关发现。

用十张纸片实现网页概率：2 张泄露、2 张补给、6 张正常。每次完成一关抽一张，记录后放回。
