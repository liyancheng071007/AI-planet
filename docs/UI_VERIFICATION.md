# 界面与交互回归说明

## 本轮修复

| 旧行为 | 新行为 |
| --- | --- |
| 后续关卡和侧栏按钮被禁用，点击没有响应 | 点击展示任务预告、奖励和解锁条件，可前往当前任务 |
| 品牌标志只有空链接 | 点击返回任务地图 |
| 手机端隐藏侧栏后无法切换节奏 | 地图顶部保留选择入口，与侧栏同步 |
| 提示使用全局浮层，可能被原生对话框遮住 | 关卡内反馈显示在对话框内部 |
| 浏览器原生校验拦截提交，用户不易理解原因 | 明确播报漏填原因，定位到需要修改的字段 |
| 关闭任务后未提交内容丢失 | 同一页面会话内恢复表单草稿 |
| 长任务中需要滚动寻找关闭与提交按钮 | 弹窗头部与操作栏固定在可见滚动边缘 |

## 浏览器覆盖

`scripts/browser-check.mjs` 使用 Microsoft Edge 无头浏览器进行实际点击，不以直接调用游戏函数替代交互。

- 八关完整通关、成绩和徽章、协作选项与金牌结算。
- 七个锁定关卡预览、解锁跳转、侧栏和轨迹导航。
- 全部 / 可挑战 / 已修复筛选与空状态恢复。
- 品牌返回地图、小队代号保存、桌面与手机课堂节奏切换。
- 草稿恢复、空表单反馈、提示词变更后必须重新生成。
- 提示和辅助费用、余额不足时在弹窗内显示反馈。
- 导出文件、打印函数调用（不自动操作系统打印对话框）、重置的取消和确认。
- 刷新恢复、损坏存档兜底、移动端页面和弹窗横向溢出检查。
- 收集并断言页面 JavaScript 错误为空。
