# AI星球 · 微信小程序前后端独立版

此目录是完整的原生小程序源码与微信云开发后端，不修改已部署网页。开发分支：`codex/wechat-backend`，网页发布分支仍为 `main`。

## 当前交付状态

- 前端：WXML/WXSS/JS，包含地图、八关表单与教学模拟、提示/辅助、护照、协作自评、教师中心、复制记录和删除存档入口。
- 后端：`game` 云函数，使用微信上下文识别账号，服务端校验八关答案，控制解锁、扣币、发奖、进度保存和删除。
- 未注册也能阅读全部源码；默认 `demo: true` 是显式本机演示，不会调用云端。测试号能否运行由开发者工具权限决定。
- **尚未在微信云环境部署、未通过开发者工具编译/真机测试、未提交微信审核。** 当前没有 AppID 与云环境，也未安装微信开发者工具，不能声称已正式上线。
- 移动版使用原生表单与规则拼贴作品，未原样复刻网页的 SVG 下载、证书下载与浏览器打印。护照可复制为 JSON；这不是 WebView 套壳。

## 更容易上手的交互

- 首页突出「开始第一关 / 继续当前关」，全部路线按需展开；新玩家先看三步玩法。
- 八关按任务拆成短步骤，数据卡每批5张；选项直接显示，漏填时定位到对应题目。返回任务会恢复当前步骤和本次进程中的草稿。
- 提示词写好后点「生成并看看作品」，再提交；返回修改后会重新生成，减少操作遗漏。
- 「需要帮助」展开后才显示提示与辅助。第八关仅保留免费方案提示；重新填入已购买辅助前会确认，防止覆盖已有选择。
- 护照优先展示已获得的徽章和可读作品；小队设置、导出和删除按需展开。教师逐关知识点也默认收起。
- 网络结果不明确时显示「确认上次操作」，复用原请求恢复结果，不要求用户手动把答案改回旧版本。演示模式校验失败后可直接修改继续。

## 注册后部署

1. 注册微信小程序，取得自己的 AppID；安装官方微信开发者工具。导入 **本目录 `wechat/`**，不要导入外层网页根目录。
2. 把 `project.config.json` 的 `touristappid` 替换为自己的 AppID。`miniprogramRoot` 与 `cloudfunctionRoot` 已配置。
3. 开通微信云开发，创建独立测试环境。在 `miniprogram/config.js` 填写 `envId`，将 `demo` 改为 `false`。环境 ID 和 AppID 不是 AppSecret；不要把密钥放进代码。
4. 在云数据库创建 `ai_planet_progress` 集合，将安全规则设为 `database.rules.json` 的拒绝客户端直接读写。云函数通过服务端 SDK 访问，客户端只调用云函数。
5. 在开发者工具右键 `cloudfunctions/game`，选择上传并部署、云端安装依赖。依赖固定为 `wx-server-sdk@4.0.2`，同时保留锁文件。选择平台支持的 Node.js 运行时，先在测试环境验证。
6. 调用 `get`，确认返回 `ok:true`；完整走完八关、重复点击提交、断网重试、两个设备同时写入和删除存档。核对第八关免费帮助和辅助关卡60分。
7. 按小程序后台当前要求完善主体、类目、隐私说明及审核资料，完成真机预览，再上传体验版、提审与发布。是否适用某个类目/主体由微信审核决定，本项目不代替审批。

当前通过 `wx.cloud.callFunction` 调用同环境云函数，不需要为此另建 HTTPS API 域名。若以后改成 `wx.request` 自建服务器，需另按微信网络能力文档配置合法域名、HTTPS 和服务端身份验证。

## 开发与检查

```powershell
cd wechat
npm run check
npm test
```

测试无需云账号。云端 SDK 本地检查：`cd cloudfunctions/game; npm ci --ignore-scripts`。此安装不等同于部署。

演示和云端使用不同本机存储命名空间；切换环境不会把演示分数上传到正式云端。云端故障会显示错误，不会自动切回演示伪装成功。

## 数据边界

- 账号文档 ID 来自服务端 `APPID + OPENID` 的哈希；不接受客户端传来的用户 ID。哈希仍是可关联标识，并非匿名数据。
- 云数据库仅存进度、数值成绩、协作自评、模拟事件和最近32个请求摘要，不存姓名、手机号、人脸、作品正文或小队代号。
- 文字答案会传到云函数做长度/要素检查，但不存入数据库，也不由应用主动打印日志。平台运行日志、备份和保留策略需在正式上线前另行确认。
- 本机保留作品与小队代号；不同设备不会同步这些内容。未提交草稿仅在当前小程序进程内暂存。
- 护照提供删除云端存档操作；删除的是当前数据库记录，不承诺清除云服务商的历史备份。
- 暂不提供多人实时房间、排行榜、作品公开分享、真实模型或支付服务。
